# _orphans/

Файлы с бэкслешем (`\`) в имени, которые нашли на сервере Timeweb
(явный баг какого-то скрипта сборки — путь склеился через `\` вместо `/`,
и они легли в корень `public_html/`, а не в подкаталог).

Канонические версии этих страниц уже есть в правильных местах
(`cases/`, `services/`) — но **содержимое отличается** от того, что тут,
поэтому вместо удаления я их сложил сюда.

| Файл здесь                            | Канонический файл                       | Размер (orphan / canon) | Дата     |
|---------------------------------------|-----------------------------------------|-------------------------|----------|
| `cases--industrial-warehouse.html`    | `cases/industrial-warehouse.html`       | 8129 / 11165            | 2026-05-04 |
| `cases--tver-square.html`             | `cases/tver-square.html`                | 8064 / 11240            | 2026-05-04 |
| `cases--velichkovo-forest-resort.html` | `cases/velichkovo-forest-resort.html`   | 8034 / 11035            | 2026-05-04 |

**Похоже на устаревшие draft'ы** (на ~3 КБ короче канонических — выглядит
как недописанные страницы кейсов без портфолио-материалов). Скорее всего
безопасно удалить, но перед этим сравни `diff` в редакторе.

## Что с ними делать при деплое

Если будешь пушить обратно на сервер — добавь `_orphans/` в `.deployignore`,
чтобы оно не уехало вместе с чистой версией.
